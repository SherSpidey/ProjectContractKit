# GDScript Style

Read the [complete writing rules](references/style-rules.md) and apply the
package's authority order and project exceptions. Check the project's Godot
version, declarations, and callers; preserve interfaces, numeric meaning, and
serialized names while changing only the intended code.

Use Godot's recommendations as defaults. Apply the project's typing and warning
policies. Godot object, scene, resource, and Editor behavior belongs to the
applicable Godot Development Skill; project choices belong to the project contract.
