# C++ Style

Read the [complete writing rules](references/style-rules.md) and apply the
package's authority order and project exceptions. Inspect declarations,
definitions, and callers; preserve semantics, ownership, public spelling, and
interface guarantees while changing only the intended code.

Review names, types, state, qualifiers, dependencies, layout, interfaces, and
comments. Respect external APIs, compiler requirements, generated regions, and
public compatibility. Keep exceptions explicit; recurring project choices belong
in the project contract when maintenance is authorized.
