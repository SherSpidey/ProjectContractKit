# C++ Style

Read [the complete writing rules](references/style-rules.md) before applying
this Skill. Use the package's priority rules: the project's agreed conventions
and exceptions determine local choices, and this profile supplies the defaults.

Understand the declarations, definitions, and callers around the target code.
Preserve semantics, ownership, public spelling, and interface guarantees while
applying the rules to new or intentionally changed code.

Review the applicable naming families, types and state, expression qualifiers,
dependencies, layout, interfaces, and comments. Respect external APIs, compiler
requirements, generated regions, and public compatibility boundaries. Keep
exceptions explicit at their owning boundary and place recurring project
decisions in the project contract when authorized.
