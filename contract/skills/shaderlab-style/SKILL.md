# ShaderLab Style

Read the [complete Unity writing rules](references/style-rules.md). When the task
reaches embedded or associated HLSL code, also read
`../hlsl-style/SKILL.md` and its full reference. ShaderLab-only property, pass,
tag, or render-state work does not require HLSL Style. This Skill supplies the
scoped Unity defaults for naming, shader file roles, and literal spelling; keep
compatible HLSL obligations in force.

Check the installed render pipeline, shader interfaces, material assets,
and property consumers. Preserve bindings and required platform spellings.
