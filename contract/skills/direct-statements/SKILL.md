# Direct Statements

State what exists, what it does, who owns it, how it is used, and what is required.
Keep version comparisons and reconstruction or refactoring narratives out of
maintained text.

Preserve obligations, scope, conditions, exceptions, and required evidence when
converting material. Place useful ownership, lifetime, numeric, failure, and
interface invariants beside the requirement or code they explain.

Apply this to headings, prose, examples, comments, and delivery text. Report
actual validation and unresolved work accurately.
